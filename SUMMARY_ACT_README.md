# Реализация Сводного Акта Передачи

## Описание
Реализована функция генерации "Сводного Акта Передачи" для выбранных строк в таблице списаний.

## Что добавлено

### 1. HTML изменения (index.html)
- Добавлено всплывающее меню для кнопки #exportXlsBtn
- Меню содержит пункт "Сводный Акт передачи"

### 2. CSS стили (style.css) 
- Добавлены стили для всплывающего меню `.summary-act-menu`
- Стили для кнопки `.summary-act-option`

### 3. JavaScript функции (script.js)

#### Основные функции:
- `collectSelectedWriteoffRowsForSummaryAct()` - собирает данные выбранных строк
- `buildSummaryActSheet(XLSXLib, rows, currentDate)` - строит Excel лист
- `exportSummaryAct()` - основная функция экспорта
- `setupSummaryActExport()` - настройка обработчиков событий
- `showSummaryActMenu()` / `hideSummaryActMenu()` - управление меню

#### Особенности реализации:
1. **Группировка по документам**: Строки группируются по systemId с пустыми строками между группами
2. **Колонка "Дата передачи"**: Добавлена между "Наименование" и "Цена, за 1 шт."
3. **Заголовок**: "СВОДНЫЙ АКТ ПЕРЕДАЧИ" вместо "АКТ ПЕРЕДАЧИ"
4. **Комплектующие**: Поддержка строк с комплектующими
5. **Подсчет итогов**: Корректный подсчет с учетом пустых строк-разделителей

## Как использовать
1. Перейти на страницу "Списания"
2. Нажать "Выделить строки"
3. Отметить галочками нужные строки
4. Нажать "Сохранить в XLS"
5. В появившемся меню выбрать "Сводный Акт передачи"
6. Файл будет сохранен с именем "Сводный_Акт_передачи_YYYYMMDD.xlsx"

## Структура Excel файла
1. Заголовок: "СВОДНЫЙ АКТ ПЕРЕДАЧИ" + дата
2. Подзаголовок: "изделий под реализацию"
3. Таблица с колонками:
   - № 
   - Наименование
   - Дата передачи (новая колонка!)
   - Цена, за 1 шт.
   - Кол-во
   - Стоимость
   - Рекомендуемая цена продажи, 1 шт.
4. Строки данных с разделителями между документами
5. Строка "ИТОГО" 
6. Подписи "Передал" и "Принял"
